# 企业员工考勤绩效管理系统 · 功能需求分析

## 创新亮点

- 🤖 **AI 智能对话预约**：基于大语言模型（LLM）与 Function Calling，用户通过自然语言多轮对话即可完成查座、预约、改签、取消，支持模糊查询兜底与上下文记忆。
- 🔄 **冲突候补与自动转正**：座位冲突时自动加入候补队列，信用分加权排序，原预约释放后优先自动转为正式预约并推送通知。
- 🤝 **AI 座位协商调换**：用户可向对方发起换座协商，LLM 自动生成礼貌文案，对方同意后系统自动完成座位互换。
- 📊 **AI 对话质量监控**：管理端实时统计 LLM 对话成功率、满意度、异常会话，支持人工介入处理。
- 🛡️ **信用分闭环约束**：按时签退加分、爽约/暂离超时扣分，信用分同时影响候补优先级，形成自助激励机制。

## 一、系统概述

本系统基于 SpringBoot 框架开发，旨在实现企业内部的员工考勤管理与绩效考核信息化，覆盖打卡、请假、审批、绩效评定等核心业务流程，支持多角色协同办公。

### 后端技术栈

- **核心框架**：Spring Boot3
- **持久层框架**：MyBatis
- **数据库**：MySQL 8.0
- **安全认证**：Spring Security + JWT

### 前端技术栈

- **核心框架**：Vue 3
- **UI 组件库**：Element UI
- **路由管理**：Vue Router
- **状态管理**：Vuex
- **HTTP 客户端**：Axios
- **图表库**：ECharts

## 二、角色划分

系统共设计 **4 类核心角色**：

| 角色 | 职责定位 |
|------|----------|
| 系统管理员 | 负责系统级配置、用户账号与权限管理 |
| 人事专员（HR） | 负责考勤规则制定、异常处理、绩效模板与报表统计 |
| 部门经理 | 负责部门内审批、员工绩效评定、团队考勤监督 |
| 普通员工 | 负责日常打卡、各类申请提交、查看个人考勤与绩效 |

## 四、消息通知与在线交流系统设计

### 4.1 系统消息通知模块

#### 4.1.1 消息类型与场景

| 消息类型 | 触发场景 | 接收对象 |
|----------|----------|----------|
| 审批通知 | 请假/补卡/加班申请提交、审批通过、审批驳回 | 申请人、审批人 |
| 考勤提醒 | 上班打卡提醒、下班打卡提醒、考勤异常标记 | 员工本人、部门经理 |
| 绩效通知 | 考核任务发布、评分待办提醒、绩效结果发布 | 经理、员工 |
| 系统公告 | HR/管理员发布的放假通知、制度更新 | 全体员工或指定部门 |
| 催办通知 | 审批任务超期未处理 | 审批人 |
<img width="1855" height="871" alt="image" src="https://github.com/user-attachments/assets/559bfa25-c93f-4d4e-8c90-050161300cc1" />

#### 4.1.2 推送渠道
- **站内信**：系统核心消息通道，所有通知默认写入站内信收件箱
- **WebSocket 实时推送**：在线用户通过 WebSocket 即时接收消息，前端显示红点 / 弹窗提醒

#### 4.1.3 消息状态管理
- 未读 / 已读状态标记
- 消息持久化存储（支持按类型、时间、关键词检索）
- 一键已读、批量删除
- 消息免打扰设置（可选）

---

### 4.2 在线交流（IM）模块

#### 4.2.1 私聊（单聊）
- 员工之间基于通讯录发起一对一即时会话

#### 4.2.2 部门群聊
- 系统自动为每个部门创建部门群，员工入职自动进群
- 支持 @某人 / @所有人
- 群成员列表展示（在线 / 离线状态，可选）
- 群消息历史记录可查询

#### 4.2.3 通讯录
- 组织架构树形展示（部门 → 岗位 → 员工）
- 支持按姓名、部门、拼音搜索
- 点击联系人可直接发起会话
- 显示员工基本信息（头像、职位、在线状态）
